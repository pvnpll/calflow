# Archived Database Schemas

These files are historical reference schemas from when the shared Supabase project (`random`) was initialized alongside sibling projects:

- **`master_supabase_schema.sql`**: Master schema script defining multi-tenant isolated tables (`cf_*` for CalFlow, `ir_*` for InstaReels).
- **`combined_database_init.sql`**: Early prototype schema script before table prefixes were finalized.

Current Calflow active migrations are located in `../migrations/`.
